BASE TRIVIA MINI APP - QUICK START
==================================

🚀 GET RUNNING IN 3 STEPS
-------------------------

1. INSTALL & RUN LOCALLY
   npm install
   npm run dev
   → Open http://localhost:3000

2. BUILD FOR PRODUCTION
   npm run build
   → Creates dist/ folder

3. DEPLOY
   - Push to GitHub
   - Deploy to Vercel/Netlify
   - Update URLs in farcaster.json and index.html


📋 ESSENTIAL FILES TO UPDATE
----------------------------

Before deploying, replace these:

1. public/.well-known/farcaster.json
   ❌ "https://your-domain.com" (all instances)
   ✅ "https://your-actual-domain.com"
   
   ❌ "0x" (ownerAddress)
   ✅ "0xYourBaseWalletAddress"

2. index.html
   ❌ "https://your-domain.com" (in fc:miniapp meta)
   ✅ "https://your-actual-domain.com"


🎨 CREATE REQUIRED IMAGES
--------------------------

Upload to public/ folder:
- embed-image.png (600×400px, 3:2 ratio)
- icon.png (192×192px)
- splash.png (600×400px)


🔗 AFTER DEPLOYMENT
-------------------

1. Generate Account Association
   → Go to: https://www.base.dev/
   → Enter your domain
   → Copy credentials to farcaster.json
   → Redeploy

2. Test Your App
   → Go to: https://www.base.dev/preview
   → Enter your URL
   → Click Launch

3. Publish to Farcaster
   → Create post with your URL
   → Embed appears automatically
   → Users can launch directly

🐛 TROUBLESHOOTING
------------------

Problem: TypeScript errors
Solution: npm install (dependencies missing)

Problem: Questions won't load
Solution: Check internet, API might be rate limited

Problem: Wallet not connecting
Solution: Must test in Base app, not regular browser

Problem: Images 404
Solution: Put images in public/ folder and rebuild

Problem: Can't play again
Solution: Clear localStorage or wait 24 hours
