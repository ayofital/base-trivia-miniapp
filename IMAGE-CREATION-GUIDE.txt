IMAGE CREATION GUIDE FOR BASE TRIVIA
====================================

REQUIRED IMAGES CHECKLIST
-------------------------

You need to create the following images before deploying:

1. ✓ embed-image.png (600×400px) - Social embed
2. ✓ icon.png (192×192px) - App icon
3. ✓ splash.png (600×400px) - Loading screen
4. ✓ hero.png (1200×630px) - Store hero image
5. ✓ og-image.png (1200×630px) - Open Graph
6. ✓ screenshot1.png (750×1334px) - App screenshot 1
7. ✓ screenshot2.png (750×1334px) - App screenshot 2


DETAILED SPECIFICATIONS
-----------------------

1. EMBED IMAGE (embed-image.png)
   Size: 600×400px (minimum) to 3000×2000px (maximum)
   Aspect Ratio: 3:2 (required)
   Format: PNG (recommended), JPG, GIF, WebP
   Max File Size: 10MB
   
   Content Suggestions:
   - App name "Base Trivia"
   - Emoji or icon (🎯)
   - Purple gradient background (#667eea to #764ba2)
   - Tagline: "Test Your Knowledge Daily"
   - Clean, readable text
   
   This image appears when your app is shared on Farcaster.

2. APP ICON (icon.png)
   Size: 192×192px (recommended), can be up to 512×512px
   Aspect Ratio: 1:1 (square)
   Format: PNG with transparent background
   
   Content Suggestions:
   - Simple, recognizable symbol
   - Target emoji 🎯 or trivia icon
   - Purple circle with white symbol
   - Should look good at small sizes
   
   This appears as the app icon in lists and navigation.

3. SPLASH SCREEN (splash.png)
   Size: 600×400px
   Aspect Ratio: 3:2
   Format: PNG
   Background: Should match splashBackgroundColor (#1e40af)
   
   Content Suggestions:
   - "Base Trivia" centered
   - Loading animation suggestion
   - Simple and fast-loading
   - Matches app branding
   
   Users see this while your app loads.

4. HERO IMAGE (hero.png)
   Size: 1200×630px
   Aspect Ratio: 1.91:1 (close to 16:9)
   Format: PNG or JPG
   
   Content Suggestions:
   - Feature showcase
   - App screenshot mockup
   - Key features listed
   - Compelling visual
   
   Used in app store and promotional materials.

5. OPEN GRAPH IMAGE (og-image.png)
   Size: 1200×630px
   Aspect Ratio: 1.91:1
   Format: PNG or JPG
   
   Content Suggestions:
   - Can be same as hero image
   - App name and description
   - Visual appeal for social sharing
   
   Shows when app URL is shared outside Farcaster.

6. SCREENSHOTS (screenshot1.png, screenshot2.png)
   Size: 750×1334px (iPhone 8 dimensions)
   Aspect Ratio: 9:16 (portrait)
   Format: PNG
   
   Content Suggestions:
   Screenshot 1: Quiz question screen
   - Show a trivia question
   - Multiple choice answers
   - Progress counter
   
   Screenshot 2: Score screen
   - Final score display
   - Share button visible
   - Tip bar (optional)
   
   These help users understand what your app does.

QUICK MOCKUP GUIDE
-----------------

For Embed Image (600×400px):
1. Create 600×400px canvas
2. Fill with purple gradient
3. Add "🎯 Base Trivia" centered
4. Add subtitle "Test Your Knowledge"
5. Export as PNG

For Icon (192×192px):
1. Create 192×192px canvas
2. Draw purple circle
3. Add white "?" or target symbol
4. Export as PNG with transparency

For Splash (600×400px):
1. Create 600×400px canvas
2. Fill with #1e40af blue
3. Add "Base Trivia" white text
4. Add small loading dots
5. Export as PNG

For Screenshots:
1. Take actual app screenshots
2. Run app at http://localhost:3000
3. Open DevTools (F12)
4. Set device to iPhone 8 (375×667)
5. Take screenshot of:
   - Question screen
   - Score screen
6. Resize to 750×1334 (2x scale)

FILE NAMING

Exact names required:
✓ embed-image.png (not embedImage or embed_image)
✓ icon.png (lowercase)

✓ hero.png
✓ og-image.png
✓ screenshot1.png (not screenshot-1)

Place in: public/ folder


UPLOAD INSTRUCTIONS
------------------

1. Create images using tools above
2. Save with exact filenames
3. Place in public/ folder:
   
   public/
   ├── embed-image.png
   ├── icon.png
   ├── splash.png
   ├── hero.png
   ├── og-image.png
   ├── screenshot1.png
   └── screenshot2.png

4. Rebuild app: npm run build
5. Redeploy to hosting

OPTIMIZATION
-----------

Before uploading:
1. Compress images (use tinypng.com)
2. Keep file sizes small
3. Use PNG for graphics, JPG for photos
4. Ensure quality is good at target size

Tools:
- TinyPNG (https://tinypng.com)
- Squoosh (https://squoosh.app)
- ImageOptim (Mac)
