🔧 KEY FUNCTIONALITY
--------------------

Quiz Flow:
1. App loads → Fetches 5 questions
2. Shows questions one by one
3. User selects answer
4. Immediate feedback (correct/wrong)
5. Auto-advances after 1.5s
6. Shows final score
7. Saves session to localStorage
8. Enables 24h cooldown

Self-Tip Flow:
1. User enters ETH amount
2. Clicks "Send Tip"
3. SDK gets wallet context
4. Converts ETH to wei
5. Shows transaction preview
6. User confirms
7. Transaction submitted to Base
8. Returns transaction hash
9. Stores in tip history
10. Links to BaseScan

Share Flow:
1. User clicks "Share to Farcaster"
2. Opens Warpcast composer
3. Pre-fills text with score
4. User can edit and post
5. Embed appears automatically


💾 LOCAL STORAGE USAGE
----------------------

Keys:
1. trivia_quiz_session
   - Last play timestamp
   - Score and total questions
   - Used for cooldown logic

2. trivia_tip_history
   - Last 10 transactions
   - Amount, timestamp, status, hash
   - Displayed in tip history UI

Can be cleared via browser DevTools for testing.
